# 全屏播放修复与验收

日期：2026-10-19 · 版本：0.2.5 · Windows x64 / Electron 44

## 原因与修改

原全屏元素是按 episode.id 设置 React key 的 Player。换集会销毁该元素，触发 Chromium 自动退出全屏。现在以稳定的 PlayerSurface 作为全屏元素，内部每集的 Player 仍独立重建，原有进度保存和资源重试逻辑不变。退出作品时会正常退出全屏。

原全屏控制栏是普通布局元素，始终占据视频下方一行。现在改为覆盖在全尺寸画面上的深色渐变浮层；播放时约 2.5 秒不操作隐藏控制栏及鼠标。暂停、控制栏交互、拖动和键盘操作保留控件。窗口模式仍采用原控制栏布局。

## 自动验收

运行 `npm run build` 后执行 `node scripts/fullscreen-qa.mjs`。脚本使用隔离数据目录、独立测试 preload 与 FFmpeg 生成的 10 秒本地视频，通过现有 manju-media 协议播放，不访问内容平台或个人记录。

首次修改前，回归在“全屏控制栏应为浮层”断言失败：实际样式为 static。修改后在真实 Electron 全屏下通过以下检查：

- 全屏视频区域高度等于视口，控制栏不占布局空间；闲置隐藏，移动鼠标恢复。
- 手动下一集、上一集保持同一个全屏 DOM 元素。
- 两次自然 ended 自动连播到第三集，期间 fullscreenchange 次数为 0。
- 暂停时闲置后控制栏仍显示。
- 退出全屏后手动选集保持窗口模式。
- 第二集结束进度已保存，renderer 无异常。

截图与机器报告位于本机 `outputs/fullscreen-qa-*/`，测试输出不随源码发布。这些检查验证播放界面和生命周期，不代表重新验收线上作品内容。原有跨版本自动安装验收缺口见更新验收记录。
