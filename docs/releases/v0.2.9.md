# 0.2.9 Windows x64 测试版 · 清晰度与倍速记忆

修复程序优先选低清导致的跨集画质变化，以及换集后倍速回到 1 倍的问题。

**[下载 Windows x64 安装包](https://github.com/lhljpt-web/hongguo-manju-desktop/releases/download/v0.2.9/Hongguo-Manju-0.2.9-Windows-x64.exe)** · [安装指南](https://github.com/lhljpt-web/hongguo-manju-desktop/blob/main/docs/installation.md)

- 清晰度按 1080p、720p、540p、480p、360p 顺序选择来源提供且可解码的轨道，不再把 1080p 排在低清之后。
- 保留原分辨率，提高本地转码的画质参数，减轻二次压缩损失。
- 升级时清理旧画质策略产生的媒体缓存，让重新准备的剧集使用新策略；保留收藏、观看进度和播放标识。
- 倍速成为本机偏好：手动上下集、自动连播、切换作品与重开软件均沿用，仍可随时切换回 1 倍。
- 保留五集提前缓冲、沉浸式全屏、搜索与分页修复。

来源只有低清或不支持解码的高清轨道时，会使用实际可播放分辨率，不能保证所有作品都达到 1080p。高清文件可能需要更多准备时间、网络流量和缓存空间。升级后的首次播放会重新准备媒体。

验证与实际抽查见 [清晰度及倍速修复记录](https://github.com/lhljpt-web/hongguo-manju-desktop/blob/main/docs/quality-speed-validation.md)。

应用更新仍需点击「立即更新」才下载，完成后点击「重启安装」升级。也可以退出旧版后覆盖安装。本项目为第三方非官方客户端，安装包未配置 Windows 发布者签名；上游可用性和来源画质仍可能变化。
