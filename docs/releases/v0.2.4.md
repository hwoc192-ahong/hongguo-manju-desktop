# 0.2.4 Windows x64 测试版 · 点击后才下载更新

修正 0.2.3 的后台自动下载行为：发现新版只提示，点击「立即更新」才下载；选择「暂不更新」继续使用当前版本，不会下载。收起提示后，顶部保留「有新版本」入口。

**[下载 Windows x64 安装包](https://github.com/lhljpt-web/hongguo-manju-desktop/releases/download/v0.2.4/Hongguo-Manju-0.2.4-Windows-x64.exe)** · [安装指南](https://github.com/lhljpt-web/hongguo-manju-desktop/blob/main/docs/installation.md)

启动与运行期间仍自动检查版本信息；下载通过校验后，点击「重启安装」才升级。收藏、观看进度与播放标识沿用原数据目录。

0.2.3 的行为不会被远程修改，仍会自动下载新版。希望避免该行为时，请先关闭 0.2.3，再手动覆盖安装本版。0.2.2 及更早版本没有更新器，同样需要手动安装一次。
