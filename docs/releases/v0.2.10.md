# 0.2.10 Windows x64 测试版 · 整剧提前缓存

将五集提前缓冲改为整部作品缓存，增加二倍速观看时的准备提前量。

**[下载 Windows x64 安装包](https://github.com/lhljpt-web/hongguo-manju-desktop/releases/download/v0.2.10/Hongguo-Manju-0.2.10-Windows-x64.exe)** · [安装指南](https://github.com/lhljpt-web/hongguo-manju-desktop/blob/main/docs/installation.md)

- 当前集优先，后台逐集准备其余全部剧集；从中间集开始时先准备后续，再补前面。
- 播放页显示“已缓存 N/总集数”、当前准备集数和“全剧已缓存”；失败或空间不足时可重试缓存。
- 当前作品的完整缓存允许超过 1 GiB，关闭重开可复用；切换另一部作品后，旧作品缓存可按大小、年龄和空间需求清理。
- 新准备前预留约 1.3 GiB 可用空间，不足时暂停；已缓存集仍可播放。缓存全剧需要相应流量、磁盘和准备时间。
- 保留高清优先、倍速记忆、全屏连播；应用安装包仍只在点击“立即更新”后下载，点击“重启安装”后升级。

**如二倍速仍追上准备进度，可先暂停，等显示“全剧已缓存”再观看。** 全剧就绪后可避免逐集下载和转码的等待；解码、渲染等原因的卡顿不能由缓存保证消除。停留详情页时即使暂停也会继续缓存，离开详情页或关闭应用才取消未完成任务，保留已完成文件。
