# 0.6.2 Windows x64 测试版 · 原生播放身份修复

修复原生播放接口 HTTP 200、空内容时的恢复流程。旧版在本地随机生成播放身份，格式正确不代表已在服务端登记；本轮对照中，登记所得身份能够稳定取得原本失败的目标分集资源。

**[下载 Windows x64 安装包](https://github.com/lhljpt-web/hongguo-manju-desktop/releases/download/v0.6.2/Hongguo-Manju-0.6.2-Windows-x64.exe)**

- 旧身份收到空响应后，向设备登记端点提交本机生成的匿名应用标识及固定客户端兼容参数，取得有效身份后重试同一集。不读取账号、手机号或真实硬件标识。
- 登记成功后原子保存身份；并发请求共用一次登记，重开应用沿用已保存身份。服务端实际返回的 16 位身份也能正确保存和读取。
- 登记失败保留旧配置，同次运行不反复登记；已登记身份仍为空时也不会循环登记。继续保留官网公开兼容播放及明确失败提示。
- 目录与榜单继续沿用原签名流程，保留收藏、播放进度、缓存及界面设置。

## 调查与验证

改时间参数、媒体类型和版本字段均未形成可重复修复；现有 Java 签名器与参考项目 Python 签名器在旧身份下均失败。使用参数一致的红果设备登记流程后，原生资源请求恢复。不能把这一客户端对照进一步解读为已经确定服务器内部全部拒绝规则。

真实网络验证原先失败的第 78 集为 45.034 秒、第 155 集为 37.634 秒，均提供对应 1080p 轨道并完成既有媒体处理。重建连接后第 1、2、78、155 集仍可取源。未用首集预览替换后续集数。

183 项自动测试、类型检查及构建通过。独立只读审查未发现阻塞问题，已采纳失败时清理登记临时文件的建议。

最终打包版验证第一集完整播完后进入第二集、第 78 集完整播完后进入第 79 集、第 155 集实际音视频解码及退出重开恢复 12 秒进度。画面实际为 1080p，分集时长与原生资源一致。

设备登记端点可能暂时失败：安装版首次登记曾失败，保留旧配置；重开后成功取得并保存有效身份。遇到相同情况可退出软件后重试。本次没有用循环登记或更换第三方身份掩盖失败。

本轮探测、媒体处理和安装包验收记录保存在本机忽略目录，不上传设备标识、签名、媒体地址或媒体文件。该版本恢复了抽查目标，不宣称逐集验收所有作品；上游服务仍可能变化。
