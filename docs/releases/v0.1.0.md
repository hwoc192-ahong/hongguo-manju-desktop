# 0.1.0 正式版

红果漫剧桌面版首个正式发行版，支持 Windows 10 / 11 x64。

**[下载 Windows x64 安装包](https://github.com/lhljpt-web/hongguo-manju-desktop/releases/download/v0.1.0/Hongguo-Manju-0.1.0-Windows-x64.exe)** · [安装与迁移指南](../installation.md)

## 功能

- 榜单、剧名搜索、分享导入、本机收藏与观看记录。
- 来源实际提供的高清画质、倍速、全屏、画中画、自动连播与续播。
- 多作品后台缓存、断点续传、缓存目录迁移、容量和下载速度设置。
- 宣纸书卷、午夜影院、流光、像素放映厅四套外观。
- 正式版更新提示，确认后下载并安装。

## 播放修复

原生接口空响应时尝试一次本机匿名设备登记，登记成功后持久化并重试所选集。支持服务端返回的有效 16 位身份；登记失败保留旧配置，不循环登记。此前失败的第 78、155 集已验证对应 1080p 资源及实际播放。

进度条支持选择未缓存位置：保留最新拖动目标，准备好后自动跳转，等待期间可改选、暂停或恢复。已缓存内容可前后拖动，接近片尾不会误回到开头。尚未到达的媒体仍需网络与处理时间，不承诺瞬时跳转。

## 从旧测试版迁移

正式版本号从 0.1.0 重新开始。旧测试版版本数字较高，需从托盘完全退出，再手动覆盖安装一次；保留原路径和应用数据，无需卸载或清空缓存。此后按递增的正式版本号更新。

安装包附源码归档、SHA-256 校验和自动更新元数据。旧测试版发行文件与标签清理后仅保留本正式版，源码提交历史继续保留。

本项目独立维护，与红果官方无隶属或合作关系。可用性受内容服务与网络影响，抽查通过不代表所有作品始终可播。
