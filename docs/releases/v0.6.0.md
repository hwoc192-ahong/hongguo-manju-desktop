# 0.6.0 Windows x64 测试版 · 四套界面风格

新增可切换的界面外观，默认仍是「宣纸书卷」，也可以随时恢复默认。

**[下载 Windows x64 安装包](https://github.com/lhljpt-web/hongguo-manju-desktop/releases/download/v0.6.0/Hongguo-Manju-0.6.0-Windows-x64.exe)** · [安装指南](https://github.com/lhljpt-web/hongguo-manju-desktop/blob/main/docs/installation.md)

- 顶部新增「外观」入口，提供四套界面方向，点击即时切换并保存在本机；再次打开软件仍会沿用。
- 「宣纸书卷」是默认外观；「午夜影院」使用深色底、暖金控件和分栏主视觉；「流光」增加左侧导航、霓虹渐变和流媒体式布局；「像素放映厅」使用街机边框、撞色阴影和像素进度。
- 外观设置面板带四张预览卡；底部「恢复默认『宣纸书卷』」可随时回到原界面。切换只覆盖配色与排版，不改变播放、缓存、收藏、观看记录或播放偏好。
- 首页、搜索、收藏、历史、播放页、选集、缓存中心、导入和更新提示都适配所选外观；流光的侧边导航包含发现、收藏、历史、缓存、导入和外观。
- Windows 原生标题栏和系统消息框仍由系统控制，不属于应用内主题范围。

150 项自动测试、类型检查和构建通过。实际 Electron 渲染覆盖四套主题的首页、播放页和缓存中心，并在 1040×720 与 1400×920 下检查顶栏和内容无横向溢出；使用本地视频验证播放页控制条、选集和缓存进度；验证了启动读取已保存主题、切换后重开保留，以及恢复默认。主题设置保存在本机，不涉及账号同步。

安装包仍为测试版且没有 Windows 发布者签名。更新时保留安装路径和 `%APPDATA%/红果漫剧桌面版/` 数据，包括收藏、观看进度、播放偏好和媒体缓存。本项目是第三方非官方客户端，相关品牌、作品、封面及其他内容的权利归各自权利方所有。
