# 0.2.7 Windows x64 测试版：播放资源兼容修复

修复 0.2.6 及更早版本在部分作品和集数上出现“内容来源返回空结果”的问题。播放请求使用本轮实测可用的批量资源接口，每次只请求当前分集，并严格核对返回编号；继续复用原有播放器标识、画质选择、媒体处理、滚动缓冲及观看记录。

[下载 Windows x64 安装包](https://github.com/lhljpt-web/hongguo-manju-desktop/releases/download/v0.2.7/Hongguo-Manju-0.2.7-Windows-x64.exe)

0.2.3 及更新版本可在应用内检查更新，确认下载后重启安装；也可退出旧版后手动覆盖安装。升级保留收藏、进度及播放器标识。

协议依据和实际验证见[本次检查记录](../health-check-2026-10-22.md)。参考协议来自公开发布组件，本项目独立实现 TypeScript 适配；没有将参考项目源码打入应用。

## 验证与已知限制

测试、类型检查和构建通过。实际播放及安装验收结果详见检查记录。上游可用性仍可能变化，抽样通过不保证全部作品或集数永久可播；首次播放仍需下载和处理完整单集。安装包尚未配置 Windows 发布者签名。
