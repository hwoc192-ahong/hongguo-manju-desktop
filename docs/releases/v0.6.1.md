# 0.6.1 Windows x64 测试版 · 恢复播放

在原生播放资源接口返回 HTTP 200 空响应时，恢复官网公开可播分集。自动使用官网公开兼容播放器提供的 MP4，继续沿用本机缓存和播放流程。**全集尚未恢复**：部分分集官网接口明确返回 403，仍无法播放。

**[下载 Windows x64 安装包](https://github.com/lhljpt-web/hongguo-manju-desktop/releases/download/v0.6.1/Hongguo-Manju-0.6.1-Windows-x64.exe)** · [诊断与验证记录](https://github.com/lhljpt-web/hongguo-manju-desktop/blob/main/docs/playback-fix-2026-10-28.md)

- 保留原播放资源链路；仅空响应时启用兼容源，不掩盖数据目录等本机错误。
- 校验响应、有效期、官方媒体域名和实际 MP4 音视频元数据；拒绝不完整或不支持的资源。
- 兼容源当前抽查为 360p，菜单显示实际可用画质，不承诺 1080p。已有高画质缓存仍可继续播放。
- 保留四套外观、收藏、进度、跨集连播与缓存设置。
- 公开资源不可用时明确提示，不将首集预览冒充所选集数；选集总数不再宣称全部可播放。

180 项自动测试、类型检查和构建通过。最终包及本机安装版均验证前两集自然播完并自动进入下一集、第三集播放及退出重开恢复 12 秒进度；第 78、155 集的 403 提示与不替换行为通过验证。

安装包为测试版，未配置 Windows 发布者签名。覆盖安装会保留现有应用数据。内容源仍可能变化，本次抽查不代表所有作品永久可用。
