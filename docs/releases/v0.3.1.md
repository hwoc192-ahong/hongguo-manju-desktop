# 0.3.1 Windows x64 测试版 · 启动更新提示

进入软件后，检测到新版本会弹出居中提示，显示当前版本和可更新版本。

**[下载 Windows x64 安装包](https://github.com/lhljpt-web/hongguo-manju-desktop/releases/download/v0.3.1/Hongguo-Manju-0.3.1-Windows-x64.exe)** · [安装指南](https://github.com/lhljpt-web/hongguo-manju-desktop/blob/main/docs/installation.md)

- 启动约 2 秒后开始检查更新，检查耗时取决于 GitHub 连接；运行期间每 4 小时再检查。
- 「暂不更新」或关闭弹窗不会下载，同一版本在本次运行中只自动提示一次；重开软件重新检查并提醒。顶部入口仍可手动更新。
- 点击「立即更新」才下载安装包；下载并校验完成后，仍由你点击「重启安装」。不会自动下载、自动重启或在普通退出时安装。
- 支持键盘操作和 Esc 关闭，默认焦点放在「暂不更新」。全屏播放时检查结果返回，弹窗也能正常显示。
- 保留多作品后台缓存、托盘继续缓存、高清优先、倍速记忆、全屏连播和个人记录。

104 项自动测试、类型检查、构建及隔离打包客户端更新流程通过，验证未点击时无安装文件请求、重开再提示、重复事件不重弹及全屏层级，见 [验收记录](https://github.com/lhljpt-web/hongguo-manju-desktop/blob/main/docs/startup-update-validation.md)。测试仅下载无害文件，未执行测试安装。

新版弹窗功能需先升级到 0.3.1；旧版可从右上角「更新」检查并确认升级，也可彻底退出旧版后覆盖安装。收藏、观看进度及缓存沿用。本项目为第三方非官方客户端，安装包尚无 Windows 发布者签名。
