修复 0.2.1 打开作品后显示“内容来源返回空结果”的问题，以及部分集数取得资源后仍无法解码的问题。

## 安装与升级

Windows 10/11 x64 用户下载 Assets 中的 `Hongguo-Manju-0.2.2-Windows-x64.exe`，关闭旧版后安装到原目录即可。无需下载源码 ZIP 或另装开发环境、Java、手机模拟器。收藏和播放进度保存在原应用数据目录，升级时保留。

`SHA256SUMS.txt` 用于核对同批文件摘要；`Hongguo-Manju-0.2.2-source.zip` 是源码，不含运行组件。

## 修复内容

- 播放接口使用每次安装固定的本地播放器标识，停止附加导致该路径空响应的旧跨 APP 签名；其他接口沿用原流程。
- 先选择内置媒体组件支持的编码，再按清晰度选择轨道。某集只有 1080p 使用兼容编码时，会选取该轨道；所有轨道均不兼容时明确提示。
- 播放标识保存于应用数据目录的 `player-profile.json`。重启、重试沿用同一标识，损坏或保存失败时明确报错，不在失败后轮换标识。

界面沿用原有布局和配色，仍先准备完整单集再起播。
