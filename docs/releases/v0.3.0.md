# 0.3.0 Windows x64 测试版 · 多作品后台缓存

新增缓存中心，想看的多部作品可提前准备，关闭窗口后驻留托盘继续缓存。

**[下载 Windows x64 安装包](https://github.com/lhljpt-web/hongguo-manju-desktop/releases/download/v0.3.0/Hongguo-Manju-0.3.0-Windows-x64.exe)** · [安装与使用指南](https://github.com/lhljpt-web/hongguo-manju-desktop/blob/main/docs/installation.md)

- 顶部「缓存」集中展示每部作品的已缓存集数、百分比、空间和下载/处理阶段，支持暂停、继续、失败重试及移除。
- 可粘贴分享内容、从收藏添加，或在详情点「加入后台缓存」。最多两条媒体任务轮转运行，当前播放优先，切换页面和作品不打断已登记队列。
- 关窗暂停视频并隐藏到托盘，缓存继续。点击托盘重新打开；菜单「退出软件」停止缓存，重开复用完整文件并恢复未暂停任务。
- 支持更换缓存目录：复制、校验后切换，失败保留原位置，成功也保留旧文件供确认后清理。默认沿用旧缓存，无需手动搬文件。
- 兼容 H.264 资源优先复用原始视频轨道，减少重复编码；失败回退编码，HEVC 等仍需转码。
- 保留高清优先、倍速记忆、沉浸式全屏和连播，以及用户确认才下载安装更新的行为。

添加队列会使用相应流量和磁盘，已登记作品可超过原 1 GiB 清理目标；建议留足整剧空间及约 1.6 GiB 准备余量。移除任务保留已完成文件，但之后可能被空间清理。软件彻底退出后不会继续缓存；没有开机自启或系统服务。

104 项自动测试、类型检查、构建、多作品真实 Electron 缓存/托盘/迁移和全屏二倍速回归通过，见 [验收记录](https://github.com/lhljpt-web/hongguo-manju-desktop/blob/main/docs/background-cache-validation.md)。同一 20 秒 1080p H.264 本地样本的处理从约 3.2 秒降至 0.26 秒；这不代表所有片源，保留原轨道可能占用更多空间。

旧版可在软件内检查更新，点击「立即更新」才下载，点击「重启安装」才升级；也可彻底退出旧版后覆盖安装，收藏、进度、播放标识和原缓存沿用。本项目为第三方非官方客户端，安装包未配置 Windows 发布者签名。
