播放页下方先找同名后续季，再展示相似题材；缓存默认四路，并可直接清理看完的作品。

**[下载 Windows x64 安装包](https://github.com/lhljpt-web/hongguo-manju-desktop/releases/download/v0.4.0/Hongguo-Manju-0.4.0-Windows-x64.exe)** · [安装指南](https://github.com/lhljpt-web/hongguo-manju-desktop/blob/main/docs/installation.md)

- **播放页推荐**：同名其他季置顶、后续季优先，再按共同分类或题材关键词推荐；显示匹配理由，支持刷新和失败重试。线上已核对原样本的第二季。
- **缓存并行数**：默认 4 路，可选 2/4/6，设置重启保留；显示近期实际总下载速度，最多同时处理 2 集视频，当前播放优先。受控网络等待样本由 5.57 秒降至 3.29 秒，不承诺公网一定提速。
- **释放磁盘空间**：缓存中心每部作品可“删除缓存”，另有“清理已看完缓存”，确认后删除视频和任务，保留收藏、历史及其他作品。“移除任务”仍保留文件。
- **普通播放缓存也可清理**：不必先加入后台队列；旧版未登记的作品需升级后打开一次以补充清单。已看完依据末集达到 95% 推断，不代表逐集核验。当前打开作品需离开详情后再删。
- 保留托盘后台缓存、目录迁移、高清优先、倍速记忆和全屏连播；更新仍须点击才下载，再确认重启安装。

121 项自动测试、类型检查、构建及实际 Electron 缓存/播放集成验收通过，含 24 个真实生成视频、离线解码、全屏倍速、删除空间释放和重启不重新下载。详见 [验收记录](https://github.com/lhljpt-web/hongguo-manju-desktop/blob/main/docs/recommendations-cache-validation.md)。

推荐依据标题和题材，非手机个性化推荐。完整单集准备后才起播，首集等待尚未消除；六路并发可能增加网络、磁盘压力。Windows 10/11 x64，第三方非官方客户端，尚无 Windows 发布者代码签名。
