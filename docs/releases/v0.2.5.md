# 0.2.5 Windows x64 测试版 · 沉浸式全屏与连续播放

修复全屏时底部始终显示浅色控制栏，以及换集退出全屏的问题。

**[下载 Windows x64 安装包](https://github.com/lhljpt-web/hongguo-manju-desktop/releases/download/v0.2.5/Hongguo-Manju-0.2.5-Windows-x64.exe)** · [安装指南](https://github.com/lhljpt-web/hongguo-manju-desktop/blob/main/docs/installation.md)

- 全屏控制栏改为画面上的深色渐变浮层，不再占据底部空间。播放时约 2.5 秒不操作即隐藏，同时隐藏鼠标；移动鼠标或键盘操作可显示。
- 暂停、操作控制栏、拖动进度或使用键盘选择控件时保留控制栏，方便操作。
- 自动连播和手动上下集均保持全屏，下一集准备资源时也不会退回窗口。
- 手动退出全屏后换集，不会重新强制全屏。视频保持原比例，不拉伸或裁切。

保留 0.2.4 的更新确认方式：发现新版只提示，点击「立即更新」才下载，下载完成后点击「重启安装」升级。也可以关闭旧版后手动覆盖安装，保留原安装路径与数据目录。

真实 Electron 全屏与本地视频回归通过：控制栏隐藏/恢复、手动上下集、两次自然播放结束自动连播、退出全屏后换集、观看进度保存。测试使用生成的本地视频，未据此声称重新验收所有线上作品。详细记录见 [全屏验收](https://github.com/lhljpt-web/hongguo-manju-desktop/blob/main/docs/fullscreen-validation.md)。

本项目为第三方非官方客户端。安装包仍无 Windows 发布者签名，内容来源及运行组件限制见仓库说明。
