# 0.5.1 Windows x64 测试版 · 更新退出修复

修复更新前后台组件未完全退出、仍占用安装目录文件的问题。无需清空漫剧缓存来升级。

**[下载 Windows x64 安装包](https://github.com/lhljpt-web/hongguo-manju-desktop/releases/download/v0.5.1/Hongguo-Manju-0.5.1-Windows-x64.exe)** · [安装指南](https://github.com/lhljpt-web/hongguo-manju-desktop/blob/main/docs/installation.md)

- 更新前停止新的签名请求，等待所有签名子进程实际退出，包括此前超时后仍未退出的进程。
- 继续等待媒体下载、处理停止和个人记录保存；后台退出或保存失败时停止安装，明确提示。
- 新安装包在卸载旧版前检查运行状态，处理本安装目录内遗留的 Java/FFmpeg。运行中的主程序须正常退出，不强制结束它；其他目录的程序不受影响。
- 保留完整视频、有效下载断点、缓存队列、收藏、观看记录及播放偏好。更新仍需点击下载，再确认重启安装。

如果旧版已提示 `Failed to uninstall old application files ... : 2`，请从托盘菜单选择「退出软件」，再运行本页的新安装包覆盖原目录。无需卸载或删除全部缓存。如果仍提示程序运行，可重启电脑后直接覆盖安装。

“2”是旧卸载器返回的失败码，不能单凭这一数字确定具体占用文件。默认媒体缓存位于应用数据目录，缓存完成本身不应阻止卸载；缓存进行中伴随的后台进程是需要处理的情况。其他电脑上的权限或安全软件问题仍需其日志确认。

173 项自动测试、类型检查、构建、真实 NSIS 升级与重启通过；完整缓存和断点摘要一致，断点实际续传并播放。受控遗留进程实验复现旧安装器退出码 2，新版覆盖安装返回 0，缓存保留。验证详情见[更新与缓存保留验收](https://github.com/lhljpt-web/hongguo-manju-desktop/blob/main/docs/update-cache-shutdown-validation.md)。本项目为第三方非官方客户端，安装包尚无 Windows 发布者签名。
