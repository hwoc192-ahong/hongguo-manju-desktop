# 0.5.0 Windows x64 测试版 · 跨季连播与缓存体验

第一季看完后，自动接上能唯一确认的第二季；观看时提前缓存下一季，没有后续季则在结束画面展示可点击的相似题材。

**[下载 Windows x64 安装包](https://github.com/lhljpt-web/hongguo-manju-desktop/releases/download/v0.5.0/Hongguo-Manju-0.5.0-Windows-x64.exe)** · [安装指南](https://github.com/lhljpt-web/hongguo-manju-desktop/blob/main/docs/installation.md)

- **跨季观看**：开启自动连播时，末集结束进入同名下一季首集，保留全屏、倍速和音量。仅标题主体一致、季数加一且候选唯一时自动衔接；不猜测缺季或重复版本。
- **提前准备与完结推荐**：确认的下一季自动加入后台缓存；没有可确认的下一季时，结束画面提供至多六部相似题材，点击播放。推荐来源失败会显示重试，不当作完结。
- **缩短首播等待**：支持的片源边下载、边处理、边播放；不兼容时回退完整准备。流式阶段仅支持定位至已缓冲位置，完整缓存后正常拖动。
- **断点与失败恢复**：重开保留未完成前缀，校验资源指纹、强 ETag 和 Range 后续传；条件不满足则重下，避免错误拼接。按网络空闲时间超时，有限次数退避重试。
- **缓存策略**：默认 20 GiB 保留额度，可调或不限；增加总下载限速和每部作品高/普通/低优先级。额度不足暂停新准备，不自动删已登记的作品。未完成缓存也能在缓存中心清理。
- **日常播放**：画中画、按分钟或再播 N 集停止；记住音量、静音、倍速、画质与自动连播。画质选择使用来源真实档位。
- **诊断导出**：手动选择位置，保存本次运行的阶段耗时与错误码；严格白名单，不包含媒体 URL、密钥或用户目录。

保留托盘后台缓存、目录迁移和删除确认。更新仍是先提示，点击才下载，再确认重启安装；不会发现新版本就直接下载。

169 项自动测试、类型检查、构建、实际 Electron 跨季/画中画/睡眠/设置验收、24 集缓存迁移清理、隔离更新确认测试均通过。线上加密 1080p 样本约 1.7 秒出画并以 2 倍速播到实际结尾，此时间仅代表该样本。安装包、运行组件和更新摘要已核验。

验证过程和限制见 [连续观看验收](https://github.com/lhljpt-web/hongguo-manju-desktop/blob/main/docs/continuous-playback-validation.md)。更高并行或整剧缓存不能保证消除源站、网络、CPU 和解码造成的所有等待。缓存额度是保留媒体与断点预算，处理中仍需额外临时空间。睡眠停止不会取消已登记的缓存；推荐按标题与题材匹配，并非手机个性化推荐。
