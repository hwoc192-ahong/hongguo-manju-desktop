# 0.2.6 Windows x64 测试版 · 提前缓冲与沉浸式连播

新增滚动五集缓冲，减少换集时重新下载和转码带来的等待，并包含上一轮全屏修复。

**[下载 Windows x64 安装包](https://github.com/lhljpt-web/hongguo-manju-desktop/releases/download/v0.2.6/Hongguo-Manju-0.2.6-Windows-x64.exe)** · [安装指南](https://github.com/lhljpt-web/hongguo-manju-desktop/blob/main/docs/installation.md)

- 先准备当前集，再在后台逐集准备后四集；第 1 集对应 1–5，第 2 集对应 2–6，接近结尾时自动缩小窗口。
- 下一集已准备完成时直接复用本机完整缓存；如果正在缓冲该集，直接接管任务，避免重复下载。
- 后台一次只准备一集；跳到未准备的剧集时优先加载选择的当前集。退出详情页、关闭软件会取消未完成任务。
- 缓存清理以 1 GiB 为目标，保护当前五集；单集上限 150 MiB，临时文件另需磁盘空间。暂停或关闭自动连播时仍会提前准备窗口内的剧集。
- 全屏控制栏和鼠标闲置后隐藏，控制栏覆盖在画面上；手动上下集、自动连播和准备下一集时保持全屏。

首次未缓存的单集仍需等待准备，网速或本机转码速度不足时不能保证零等待。后台失败不会替换作品或打断当前播放；点击相应剧集仍可重试。

更新方式保持用户确认：发现新版只提示，点击「立即更新」才下载安装包，完成后点击「重启安装」升级。视频提前缓冲与应用更新下载是两个独立流程。

真实 Electron 验收采用本地生成视频、生产 preload 和缓存模块、HTTP 下载及随包 FFmpeg，验证五集缓冲、下一集缓存复用、补入第六/七集、全屏连播、跳集与离页取消。没有据此声称所有线上作品或网络条件都能即时播放。详细记录见 [缓冲验收](https://github.com/lhljpt-web/hongguo-manju-desktop/blob/main/docs/buffer-validation.md)。

本项目为第三方非官方客户端；安装包尚无 Windows 发布者签名，内容来源及运行组件限制见仓库说明。普通用户下载 `.exe`；`latest.yml` 用于应用内更新，源码 ZIP 不能直接安装。
