# 独立红果免费漫剧接入验证

日期：2026-10-14。结论：**独立 APP 身份的分享导入、详情、完整播放及指定漫剧榜单已经实测可用；原生搜索和独立首页未通过，因此尚未完成整套独立接入。**

这里的“独立身份”指网络请求采用官方独立 APP 的应用参数，不代表已证明所有服务和签名内部组件均来自该 APP，也不代表这些作品只在独立 APP 出现。

## 身份依据

官方应用宝条目：<https://sj.qq.com/appdetail/com.kylin.read>。
静态检查官方 APK，未安装或执行 APK。包名为 `com.kylin.read`，应用名称「红果免费漫剧」，公司为海南愉阅科技有限公司。请求使用 `aid=8704`、`app_name=kylin_read`、版本 `7.4.0.32/74032`。短剧对照包为 `com.phoenix.read`，`aid=8662`。

APK SHA256：`26d1374c02dc7026b8e3ecba6769c402ce22607ffc3b95d31fd326945d11655a`。
详细证据见 `research/independent/identity/IDENTITY-REPORT.md`。

原已发布客户端本来就使用 aid 8704，但混用了 `app_name=novelread`、旧版本参数和 `hongguoduanju.com` 网页搜索。因此不能准确地把整个原客户端归为“只接入短剧漫剧模块”，也不能把 aid 相同视为完全独立接入证明。

## 实测结果

| 能力 | 结果 | 实测范围与限制 |
| --- | --- | --- |
| 分享导入 | 通过 | 用户提供的官方分享链接；标题、155 集数量和逐集编号顺序与详情一致 |
| 剧集详情 | 通过 | 两部指定样本及一部新榜单作品，均得到完整分集列表 |
| 完整播放 | 通过抽样 | 两部样本各播放前 3 集、中间集、末集，共 10 集；另播放榜单新作品第 1 集 |
| 进度拖动 | 通过抽样 | 上述 11 集均跳到中点并恢复播放 |
| 跨集播放 | 通过实验程序 | 样本前 3 集按 ended 事件依次切换；本次未重新验收正式桌面 UI |
| 指定漫剧榜单 | 通过 | `comic_series_rank` 下推荐榜返回 15 部作品，分页标记有效；新卡片进入同一详情/播放流程 |
| 原生关键词搜索 | 未通过 | HTTP 200，但响应体为 0 字节；两个样本均无有效搜索结果 |
| 原生联想词 | 未通过 | 依据 APK 的 `q` 字段和搜索来源枚举请求，返回 code 100103 |
| 独立 APP 首页 | 未通过 | 指定 comic_series=32 仍返回 tab_type=8 及短剧作品，不能当成独立漫剧首页 |

播放使用 Chromium 视频元素，3 倍速从头播放到 ended，实际播放时长与详情/资源时长一致；随后中点 seek 并恢复。decoded frames 和 audio bytes 均大于零。自动化为静音播放，**未进行人工听音、手机 APP 逐集内容对比，也未观看所有集**。结论不是仅基于取得视频 URL 或超过 30 秒。

新榜单作品《糯糯下山，师兄们都慌了》：series_id `7677801492920667198`，63 集；第 1 集完整播放约 138.44 秒，4153 个解码视频帧，音频解码字节数 2243498，中点拖动/恢复成功。

榜单请求明确选择 `comic_series_rank`（漫剧）；同一接口的 `ai_playlet`（AI 剧）是另一栏目。本次没有选 AI 剧栏目。但接口的栏目分类不能证明作品制作技术，也不能证明内容在两个 APP 之间不重叠。

## 仍未解决的问题

1. **搜索失败原因尚未确定。** 使用相同搜索参数、两种应用身份和两台已知主机进行 8 项对照：两种身份的搜索均 HTTP 200/0 字节，联想词均 code 100103。短剧对照版本并非同步核对的新 APK，仅用于排除“只要换 aid 就成功”的简单假设，不能视为真实短剧 APP 的完整请求对照。空响应不等于搜索无结果，错误码也不证明服务不存在。
2. **首页路由或上下文尚未还原。** APK 栏目枚举确认 comic_series=32、video_episode=8。请求指定 32 仍返回 8，因此拒绝将其输出用于独立漫剧首页。
3. **路径版本处理尚未追到最终值。** APK 生成 RPC 使用 `/reading/bookapi/search/tab/v:version/` 模板。沿 RPC、请求组装和 KMP 网络管理追踪，尚未证明实际请求最终使用哪个版本；先前 v1…v9 的探测属于推测性诊断，不是 APK 证实的路由，均未取得搜索数据。
4. **签名运行组件仍复用既有 SDK。** 内部身份为 `com.dragon.read.oversea.gp/68132`，未替换为独立漫剧 APK 的 SDK。实际请求参数为独立漫剧身份，但不能声称整套内部组件完全来自独立漫剧。
5. **榜单 cell_id 沿用已验证来源。** 尚未从独立首页自动发现该编号；已证明独立身份能访问指定漫剧榜单，未证明它对应独立 APP 当前首页布局。

设备注册、运行态或客户端配置缺失属于可能解释，**没有证据确定其为根因**。后续应通过独立 APP 正常运行时的实际请求和响应作对照，重点核对最终路径、公共参数及首页栏目配置；避免继续猜测参数或版本。运行态对照用于研究，桌面客户端最终目标仍是不要求手机或模拟器常驻。

## 对客户端的影响

本次实验脚本位于 `scripts/independent-*.ts`，与正式界面/接入层分开。未修改正式 transport/provider，未重新打包安装，用户收藏与观看记录未变。

在搜索和首页验证通过前，不把当前版本宣传为完整独立 APP 客户端，也不静默把短剧网页搜索称为独立漫剧原生搜索。现有播放、分享、榜单可以继续作为已验证能力；完整迁移仍有上述前置缺口。
