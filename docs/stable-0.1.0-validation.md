# 0.1.0 正式版验收

## 进度拖动故障与修复

旧包限速实测：第 1 集本地流只缓冲约 0.485 秒时，拖动到 48 秒被直接拒绝，进度条没有保留所选位置。未限速且媒体已经完整准备时，原有本地 Range 播放可正常拖动；故障集中在逐步处理或初始准备期间。

修复后允许在已知总时长时选择任意有效位置，不依赖目标是否已经缓存。未就绪的位置先保存为待跳转目标，暂停旧位置播放，媒体就绪后自动跳转；后续拖动覆盖旧目标。临时媒体时间不会覆盖待跳转进度，手动接近片尾也不会触发“重开已完结分集”的归零逻辑。

等待期间播放/暂停按钮控制就绪后的播放意图；已暂停的拖动保持暂停。换集或换源时，已有身份和生命周期检查阻止旧异步结果覆盖新分集。

## 已完成检查

185 项自动测试、类型检查和构建通过。独立只读审查发现的等待播放意图问题已修复并复核。

最终打包程序限速实测：

- 约 0.485 秒缓冲时连续选择 48→32→48 秒，保留最后目标。
- 等待时暂停和恢复，就绪后自动播放 48 秒位置，音视频正常解码。
- 向后跳到 12 秒并保持暂停。
- 手动跳到 59.5 秒保持目标，不返回片头。

正式版采用稳定更新渠道，关闭测试版更新。重新编号后，旧测试版需手动覆盖安装一次，应用标识与数据目录保持不变。
