# 缓存进度展示

用户需要明确知道缓存完成多少。0.2.10 只在播放器下方显示集数和当前准备集数，没有进度条和单集进度；较小窗口下文字容易落在首屏之外。

采用播放器上方独立进度卡片：整剧按已完成下载、兼容处理和保存的集数计算百分比，显示已完成集数与总集数。按集数计算便于理解，不声称是总字节比例或剩余时间；当前集未处理完成不增加完成数。

当前任务单独显示获取资源、下载、处理或保存阶段。下载百分比取实际写入字节与资源总字节；处理百分比取 FFmpeg 已输出时间与完整时长，成功退出和保存前最多 99%。重试从新任务的阶段开始，取消或切换后不显示旧任务进度。信息经已有缓存状态 IPC 每秒读取，不传递媒体地址或密钥。

全屏控制栏中提供简短集数、总百分比和当前任务状态，与控制栏一起自动隐藏，不增加常驻底条。错误和空间不足继续提示并提供缓存重试。保留整剧调度、高清策略、倍速记忆及更新确认方式。

新增自动回归先验证旧实现缺少进度而失败，再验证真实流分块下载和处理输出跨块时的阶段、百分比和完成时机。真实 Electron 与本地八集 HTTP 视频验证首屏可见性、下载过程、全部完成、全屏进度和原有二倍速连播；打包后核对构建与更新元数据，完整上传附件再发布。
