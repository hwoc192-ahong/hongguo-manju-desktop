# 启动更新弹窗

目标：用户启动客户端后检测到新版本，以居中弹窗明确提示，用户同意后才下载安装包。沿用米白、朱红样式及现有更新器。

现有方案为顶部小面板；系统原生提示不便沿用当前界面与更新操作，采用 React 居中弹窗。显示当前版本、新版、说明和“立即更新 / 暂不更新”，支持关闭、Esc、键盘焦点循环。每个版本每次启动自动提醒一次；拒绝后保留顶部入口，重开软件再次检测。无更新不弹窗，检查失败在原更新面板提示。下载和安装仍分别需要明确点击。

- [x] 用隔离打包客户端及本地无害更新源验证：进入后自动弹窗、未点击不请求安装文件、拒绝及重复事件不重弹、重启再提示、显式点击才下载、下载后不自行安装。
- [x] `UpdateControl.tsx` 增加弹窗和一次提示状态；保留原面板负责手动检查、下载进度和安装确认；`styles.css` 配套样式。
- [x] 启动检查从约 10 秒提前至约 2 秒，运行期间 4 小时周期沿用。无需新增 IPC、外部依赖或改变更新源。
- [x] 类型检查、自动测试、实际 Electron 更新流程及视觉检查，升级 0.3.1，更新说明、打包校验和 GitHub 发布准备。
