# 清晰度与倍速修复

用户报告各集忽清忽糊、倍速换集后重置。检查确认原轨道排序为 540p、720p、480p、360p、1080p，且播放器按集重建并以 1 倍初始化。

修复采用以下边界：

- 保留已验证的可解码编码过滤，画质改为优先 1080p，依次回退 720p、540p、480p、360p；显示真实选择，不伪造高清。
- 保持原分辨率转码，CRF 从 25 改为 20，减轻额外有损压缩。五集缓冲、单集 150 MiB 和约 1 GiB 缓存清理目标不变。
- 缓存增加策略标记；旧策略媒体在初始化时清理，不能升级后继续命中旧低清或强压缩缓存。观看库与安装播放标识不改。
- 倍速状态移到应用层，以本机 localStorage 保存。每个新播放器在 metadata 就绪及用户修改时应用同一值；允许正常改回 1 倍。保存失败保留本次会话设置并提示。
- 不同作品可能本身具有不同的高清轨道。最高可播放质量优先可以消除程序主动选低清，不能保证来源素材的主观画质相同。高清准备更费网络和 CPU。

验证先增加排序、缓存迁移和真实播放器倍速失败用例，再实施修复；覆盖同集重试、手动换集、自动连播、切换作品、真实进程重启、全屏与五集缓冲。发布 0.2.9 Windows x64 测试版，更新仍由用户点击下载及安装。
