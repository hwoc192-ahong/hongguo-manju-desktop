# 后台多作品缓存与目录管理

目标：缓存可跨页面、跨作品并持续运行，关闭主窗口驻留托盘；缓存中心清楚显示每部作品进度。升级保留原缓存、观看记录、倍速与手动确认下载安装更新的行为。

## 技术判断

2026-10-24 真实播放诊断的两部作品单集准备约 14–16 秒，主要耗时为 HEVC 到 H.264 的兼容编码。单纯移动目录不能保证提速。采用兼容 H.264 轨道优先尝试无损封装，失败回退既有兼容编码；其他编码维持现有高清参数。固定两条媒体任务并行、作品轮转，当前播放优先，不为任意多部剧启动无限进程。

缓存目录由主进程系统选择器选择，应用仅管理专用 HongguoManjuCache 子目录。迁移暂停任务、取消未完成临时文件、检查空间并逐文件复制校验；目录配置原子写入成功后切换，旧目录保留防止迁移破坏数据。失败回到原目录及任务状态，不自动删除用户目录。默认保持原媒体目录，迁移是可选项。

## 组件及步骤

- [x] `media.ts`：保留单集下载、Range 和校验；增加有界并发、作品轮转目标、逐作品快照、保护已登记作品缓存；旧单窗口 API 保持兼容。添加独立任务测试验证多作品并行、暂停、离页继续、优先级及去重。
- [x] `cache-manager.ts`：原子保存缓存设置与作品任务，管理添加/暂停/继续/移除，重启后复用已完成文件；任务中只保存作品和分集信息，不保存媒体地址、签名或密钥。最多 100 部作品，每部最多 5000 集；移除任务保留已完成文件，界面说明。
- [x] `media.ts` 目录迁移和 H.264 无损封装路径：测试进度、失败回退、迁移失败回滚以及播放缓存复用。通过实际 FFmpeg/Electron 测试验证速度与解码，不能仅凭命令成功声称可播放。
- [x] `main.ts`/`preload.ts`/`types.ts`：受限 IPC 添加缓存管理能力；目录只能由主进程对话框选择；增加托盘，关窗暂停视频、保存进度并隐藏，后台继续。托盘退出和更新重启均正常清理进程并保存队列。
- [x] `CacheCenter.tsx`/`App.tsx`/样式：新增顶部“缓存”入口。摘要展示运行/暂停/完成数量，列表含封面标题、集数与百分比、活动阶段、失败提示与操作；目录卡展示路径、空间、迁移状态；播放页继续显示当前作品进度。离页后可以同时查看多部剧继续增长。
- [x] 自动测试、类型检查、生产构建及真实本地多作品 Electron 验收；验证托盘关窗后任务继续、重新显示、退出重开复用、目录迁移、源不可用后播放缓存、全屏倍速回归。升级版本、文档截图与安装包校验；发布步骤见版本发布说明。

已自查：总进度仅按完整可播放集数计算，下载/处理进度单独显示；并行总数为 2 而非每部 2。暂停只停止后台任务，用户主动播放仍可准备当前集。空间不足暂停所有新后台准备，现有缓存可播放；任务关闭和重启不重复下载已完成文件。关闭主窗口继续运行已由用户确认。
