# 播放推荐与缓存管理

用户授权本轮直接完成并发布，不增加设计确认轮次。沿用米白、墨黑、朱红样式。

## 设计与取舍

播放页底部新增推荐，先展示根据标题核对的同名其他季，再展示题材相似作品。采用现有来源检索和题材关键词排序，暂不建立账户画像或远程推荐服务。精确核对标题主体，阿拉伯/中文季数归一化；不把模糊搜索结果直接当续季。请求失败和无匹配明确显示，可重试；推荐不阻塞正片。下游仍使用同一作品详情和播放流程。

缓存默认并行准备 4 集，可选 2/4/6 并持久化；单独限制最多同时运行 2 个 FFmpeg，避免盲目提高 CPU 并发。保留当前集优先、作品轮转、暂停、取消、空间保护与迁移。显示近期真实下载速率。并发不是保证提速，网络、签名和转码仍可能限速；用同一受控样本对比 2/4 集准备耗时并回归播放。

每部缓存作品提供「删除缓存」，显式确认后停止任务并删除对应媒体和索引、释放磁盘空间；不删除收藏/历史，也不删除其他作品或目录。缓存中心提供「清理已看完」：依据现有观看记录的末集接近结束判定，在界面准确标记，显示待释放空间并确认。该判断不等价于逐集观看审计。删除失败保留可重试入口，不声称全部释放；当前打开作品不允许删除，避免中断播放。重启后不重新下载已删除队列。
