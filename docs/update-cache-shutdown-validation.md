# 更新与缓存保留验收

## 问题与结论边界

用户在另一台电脑更新时看到 `Failed to uninstall old application files. Please try running the installer again.: 2`。本机的进程状态不能解释远端电脑的实际文件占用；尚未取得那台电脑的安装日志，不能确定其唯一原因。

electron-builder 的 `installUtil.nsh` 将旧卸载器退出码拼在提示末尾，因此这里的 2 是旧卸载器返回值，不能直接当作 Windows 文件不存在错误。旧卸载器在更新时移动安装目录文件，遇到占用会中止。默认缓存位于应用数据目录，完成缓存本身不应造成安装目录卸载失败。

源码检查发现：签名服务只调用 Java 的 `kill()`，不等待进程 `close`；进程引用清空后，迟到请求可能重启它。媒体缓存本身已有停止下载/处理的等待流程。0.5.1 增加不可重启的终止流程，等待包括旧超时进程在内的全部签名进程退出，再执行安装；失败则停止安装。

新安装器在卸载旧版前检查运行状态，主程序仍运行时要求用户正常退出；只结束安装目录下两个确切路径的残留 Java/FFmpeg，不按进程名批量结束，不删除缓存。检查失败会停止安装。使用 CIM 的可执行路径与进程创建时间核对身份，兼容 32 位安装器启动的 PowerShell 与 64 位媒体组件。安装检查日志在 `%TEMP%\HongguoManju-install-runtime.log`，含安装路径，不含媒体地址或凭据；反馈前可遮盖用户名。

## 自动与实际安装验证

2026-10-24，Windows x64：173 项自动测试通过（25 JavaScript、148 TypeScript/播放状态），类型检查和生产构建通过。新增失败回归先确认终止流程缺失，再实现修复。

- 更新关闭等待真实子进程退出；旧重试进程尚未退出时不能提前结束；终止后迟到请求不能重新启动服务。普通 `close()` 后仍可正常重试。
- 子进程无法结束时明确失败；原有下载结束边界、迟到资源、更新下载确认测试继续通过。
- 分别通过 32/64 位 PowerShell 启动真实 FFmpeg，验证主程序运行时不强杀、不提前结束其任务；主程序退出后只结束当前安装路径组件；其他目录的 FFmpeg 保持运行。完整和半截缓存内容不变，含单引号的路径可用。

`scripts/update-cache-shutdown-qa.mjs` 使用单独 appId、卸载注册项和 `outputs/` 安装目录，未覆盖用户真实安装。内容来源替换为本地视频与 HTTP 服务，主进程、更新、媒体缓存、Java、FFmpeg 和 NSIS 均实际运行。旧基线使用 0.5.0 的主进程和签名源码；测试中的应用名称与数据路径固定为隔离位置，确保安装器自动重启仍使用隔离数据。

实际完成：

1. 旧版准备一集 2,972,151 字节的完整视频，另一集下载到 262,144 字节后保持等待，同时存在真实 Java 与渐进 FFmpeg。
2. 发现更新不下载；点击才取得真实 NSIS，确认重启后完成旧版卸载、新版文件替换和自动启动。
3. 核对完整视频和半截视频升级前后大小及 SHA-256 一致，收藏与第 7 秒观看记录保留。
4. 新版对未完成视频发送 `Range: bytes=262144-`，完整集不重新下载；新版退出后安装目录下无 Java/FFmpeg 残留。
5. 人为保留本安装目录的 Java 子进程，再运行真实新安装器，检查释放遗留进程且缓存保留。
6. 放行未完成下载后两集均完整缓存，实际 Electron 播放器产生解码帧。

`scripts/legacy-runtime-uninstall-qa.mjs` 进一步在相同隔离身份中保留 Java 进程，并给旧安装器设置受限 PowerShell 的回退环境：旧安装器实际显示与用户截图相同的 `Failed to uninstall old application files ... : 2`，确认弹窗后退出码为 2，Java 仍在运行。直接运行新版安装包后退出码为 0，遗留 Java 退出，完整缓存的 SHA-256 不变。该实验验证一条可导致此报错的进程占用路径，不证明远端电脑采用相同策略或具有完全相同根因。旧安装器的错误框需手动确认，测试脚本不自动处理其他程序窗口。

另以实际打包客户端完成更新提示、暂不更新、全屏提示、键盘焦点、再次启动及点击后单次下载测试，保留两次确认的更新行为。

## 限制与处理

这是本机隔离身份下的真实覆盖升级，不是对故障电脑的远程复现，也不是全新 Windows 电脑验收。网络、安全策略、目录权限或防护软件仍可能造成其他安装失败；不应将所有失败归结为缓存。PowerShell/CIM 被系统策略禁止时，安装预检会停止并提示，不会绕过机器策略或清空缓存。

旧版若已失败，请从系统托盘退出软件，再下载 0.5.1 安装包覆盖原目录。无需卸载或清空全部缓存；仍有占用可重启后直接覆盖安装，并保留错误提示与安装检查日志用于定位。
