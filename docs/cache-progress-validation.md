# 缓存进度验收

日期：2026-10-23，版本 0.2.11，Windows x64。

## 显示方式

缓存卡片从播放器下方移到上方，提供朱红色进度条、已缓存集数和总百分比。整体百分比按完成集数计算，下载完成但仍在处理的单集不计作已完成；当前任务另显示实际下载百分比与 MiB，或视频处理百分比。获取资源和保存阶段不虚构百分比或剩余时间。

全屏时只在控制栏内显示简短缓存状态；播放中闲置后一起隐藏，暂停或移动鼠标后显示。失败和空间不足仍提供重试。当前缓存目录、整剧调度、跨重启复用、高清选择与倍速偏好保持原行为。

## 自动验证

新增回归在旧实现失败，实际缺少 `active.stage`；实现后 `npm test` 共 92 项通过，类型检查和生产构建通过。测试通过真实 ReadableStream 分块输入检查写入 3/6 字节报告 50%；FFmpeg 输出跨消息分块时仅处理完整行，输出 0.5/1 秒报告处理 50%，处理完成前最多 99%，成功保存后才增加缓存集数。结束或离页后活动进度清除。

## 真实播放器

`node scripts/buffer-qa.mjs` 使用实际 Electron、生产 preload/MediaCache、真实本地 HTTP 和随包 FFmpeg。八集生成视频逐集分两块传输，验证以下行为：

- 首集下载到 50% 时，整剧为 0/8，下载字节与百分比可见；进度条位于播放器上方，1280×800 窗口首屏可见。
- 全剧处理完成后为 8/8、100%，显示“全剧已缓存”。
- 全屏控制栏显示 8/8 和 100%；内容来源停用后，二倍速手动下一集和自然结束连播保持全屏并继续播放。
- 跳集、离页、重开后保留缓存，重开未重新下载，倍速仍为 2 倍。

本机报告 `outputs/buffer-qa-1792759855964/report.json` 为通过。`node scripts/fullscreen-qa.mjs` 同时通过控制栏自动隐藏、暂停显示、手动/自动换集和倍速跨进程复用，报告 `outputs/fullscreen-qa-1792759855982/report.json`。进度截图为本地生成测试视频，非线上作品截图。

以上不等于所有来源作品验收，未覆盖全新 Windows 机器安装环境；缓存完成不能保证消除硬件解码或渲染原因的卡顿。
