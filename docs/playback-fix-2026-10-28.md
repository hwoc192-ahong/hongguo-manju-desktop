# 2026-10-28 播放故障与 0.6.1 修复

## 诊断

安装版 0.6.0 可加载榜单、搜索、分页和详情，但播放《天灾末世，她囤满物资后所向披靡！》以及《末世躺赢指南：到末世十年后第一季》失败。两部各抽查前两集，原生批量播放资源接口均返回 HTTP 200、Content-Length 0，客户端报 API_EMPTY。

相同请求经 Node、curl、直连及本机代理均得到空响应；两个既有 API 域名、既有签名对照和公开参考协议对照也没有恢复。该证据可定位到原生播放资源请求路径，不能据此断言上游整体停服，亦不能证明具体风控或服务端内部原因。

静态核对官网当前播放器脚本 player.270538f230.js、8.494b68e80c.js：官网现通过 /api/video/protected/play-info 取得分离 DASH 音视频，同时提供 /api/video/protected/fallback-play-info 兼容播放接口（POST，仅提交 item_id）。官网兼容接口对相同分集返回有效响应，其 MP4 能实际解码完整音视频。因此本轮修复使用官网自己的公开兼容流程，无需复制浏览器或第三方账户凭据。

## 修改

原生播放返回 API_EMPTY 时使用兼容接口；其他故障保留原错误。校验接口状态和有效期，只接受 HTTPS 官方 hgweb/reading 媒体域名，禁止凭据、非默认端口和重定向。读取不超过前 1 MiB 的 MP4 元数据，要求完整 moov、单 H.264 视频与 AAC 音轨、有效大小和时长；从实际文件计算画质，不冒称原高清轨道。媒体 URL 留在主进程，不写入观看记录或诊断日志。

兼容源继续使用既有可续传下载、转码、逐步播放及缓存机制。本轮抽查兼容源为 360p，已有高画质缓存可继续使用。超过元数据范围、不同编码或上游不可用时会明确失败，不伪造可播放结果。

## 验证

新增回归先在旧 provider 上复现 API_EMPTY，再验证切换成功；另以 403 回归验证不会替换成预览。180 项自动测试、类型检查和构建通过。独立只读审查未发现阻塞项；审查指出的 URL 测试提前触发有效期校验问题已修正，确保实际覆盖域名、协议、凭据和端口拒绝。

原失败分集的兼容资源解析得到：首部 216.039 秒，第二部 60.034 秒，均为实际 360p、H.264/AAC。打包程序真实搜索、分页及首项打开已恢复。

随机抽查《末世躺赢指南》第 78、155 集时，官网兼容接口返回 403 public_fallback_unavailable，普通网页播放接口亦返回 403 protected_playback_unavailable。隔离浏览器访问第 78 集官网页面时提供的实际媒体时长约 60 秒，与第 78 集约 45 秒不符，并提示去 APP 看全集；这是首集预览，不纳入所选分集验收。客户端对此明确报错，未尝试替换分集或绕过访问限制。因此本版属于公开可播分集的兼容修复，全集仍未恢复。
