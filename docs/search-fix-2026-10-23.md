# 2026-10-23 搜索故障修复：0.2.8

## 原因与资料核对

0.2.7 的搜索依赖官网 HTML 内嵌的 `_ROUTER_DATA.loaderData.searchList`。今日该页面返回前端加载壳，不再提供该内嵌列表，旧客户端因此报 `PAGE_DATA_MISSING`。本机播放及榜单检查正常，不能把这次故障归为播放接口失效。

静态阅读官网当前发布的搜索脚本（`search.fe0ab865c5.js`、`async/search_(keyword)/page.140f4a1759.js`、共享模块 `t.d1c39a18e1.js` 和 `k.024362f390.js`），确认新流程为 `GET /api/search/result?query=关键词`，后续页使用 `page=2` 等页号；每页按十条来源结果推进。接口返回 `searchList`、`pageNum`、`totalPages` 和 `hasMore`。

初始探测曾收到 HTTP 502 `upstream_unavailable`，后续正常返回。因此改用当前协议可以修复页面解析失效，但不能消除上游自身的间歇性失败。没有执行下载的安全脚本、复制浏览器账号凭据或将其他片单当作搜索结果。

## 修复

- 搜索直接请求同域官方 JSON 接口，用既有大整数安全解析保留作品编号。
- 依据官网限制接受最多 30 字关键词；页号由来源游标转换，不按过滤后的卡片数推进。
- 校验页号、总页数和下一页状态，拒绝缺失或矛盾的分页数据。
- 跳过没有作品 `video_data` 的演员卡片；保留真实作品标题和编号，不强行改写为输入关键词。
- 继续同域 HTTPS 跳转限制、响应体上限和超时；临时 HTTP 失败最多重试一次，持续失败明确报错。

官网可能提供近似匹配或推荐作品，即使输入无意义关键词也可能有返回。本项目不据此承诺精确搜索或完整片库；用户仍需核对标题和季数。
