## 参考项目的可移植部分

用户给出的 waligoraamodio288-rgb/hongguo-desktop-releases 是发行仓库，不公开桌面 APP 源码。README 描述 WebView2、内置本地内容/签名服务；其第三方对应源码附件主要是 FFmpeg/OpenJDK，不包含私有应用源码。

参考 TV APK 静态观察给出了新版单集 POST /novel/player/video_model/v1/，body 使用 video_id、content_type=1、biz_param.video_platform=3。本次使用新鲜签名后，aid=8704 的参数实验可获取两部漫剧的资源；并非只修改旧短剧请求里的 aid。

资源为 CENC AES-CTR 加密，编码标记 bytevc1；浏览器直接使用这些地址能读取时长，但无法验证解码和播放。研究用媒体处理后已完成上述播放测试。签名研究没有使用手机、完整 Android 模拟器或账号；运行的是本机 JVM/unidbg SDK 指令模拟。第二阶段已独立实现运行组件自动管理，验收与打包记录见桌面版报告。

## 已识别的问题与修正

早期 fragmented MP4 验证不能跳转；现在使用具有索引的 MP4，并支持 Range。FFmpeg 的 exit=0 也可能伴随远程读取不完整：实验曾生成 19.87 秒与 51.27 秒的不完整文件。现在先校验源资源的实际字节数与 API size，再校验解码输出时长；不足时重新解析并重试一次，不接受截断内容。子进程输出在 close 后结算。

历史 signed-full-playback.json 和 v2 是失败/诊断证据，不用于本次通过判定；最终播放证据见 signed-full-playback-v3.json 和 current-result.json。

## 许可与阶段边界

zhangbaio/hongguo 和 zero199901/fqnovel-unidbg 的 GitHub 元数据 license 均为 null，根许可证 API 均 404；这是“未找到许可”，不代表许可不存在，也不等于可随意复制。相关 Java/密钥处理代码仅保存在忽略目录用于本机研究，没有纳入项目 GPL 可分发源码，也没有包装进安装包。

第二阶段已采用独立编写的 Java 桥接与 TypeScript 媒体流程，未复制未明确许可的研究仓库业务类。SDK 二进制再分发许可仍未核实，当前仅限用户本机个人构建。正式客户端的安装、播放、记录保留及尚未完成的全新 Windows 机器验收见桌面版报告。
